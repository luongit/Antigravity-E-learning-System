# Scripts Directory

> **Lưu ý:** Toàn bộ động cơ lõi bất biến của hệ thống đã được chuẩn hóa và chuyển vào thư mục **`core/`**.

- Thư mục này chỉ lưu trữ tiện ích cài đặt môi trường ban đầu:
  * `prepare_env.py`: Cài đặt thư viện phụ thuộc cho môi trường máy trạm.
- Các mã script phát sinh trong quá trình AI Agent thực thi theo từng video được gom vào thư mục **`runtime/tasks/`** (an toàn để dọn dẹp hoặc xóa bỏ).
